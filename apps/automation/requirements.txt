# Automation service dependencies.

# Alembic migrations run through a blocking driver.

# Celery, for the worker that runs pipeline jobs off the request path. Named
# directly rather than through core-py's `[tasks]` extra: the image installs

# resolve the same package twice.

# PDF inspection, compression, sample extraction and metadata. Pure Python — no
# poppler, no mupdf, no native renderer. That is a deliberate limit: it means no
# page rasterisation, and covers are extracted from embedded images instead. The
# trade is a much smaller image and one fewer class of memory-safety bug reachable
# from an uploaded file.
pypdf>=5.1.0

# Cover and thumbnail derivation.
pillow>=11.0.0
